# Visual Vocabulary

Двуязычный учебный справочник по выбору визуализаций данных. Каталог содержит
72 интерактивных примера на русском и английском языках.

Публичная версия:
<https://dvbelkin.github.io/visual-vocabulary/>

## Стек

- Astro и строгий TypeScript;
- Apache ECharts с модульными импортами;
- D3 для SVG-карт и специализированной геометрии;
- MapLibre GL JS для интерактивных карт;
- deck.gl для гексагональной агрегации, дуг потоков и движущихся маршрутов;
- статическая сборка и GitHub Pages.

## Локальная разработка

Требуется Node.js 24.

```bash
npm ci
npm run dev
```

Основные проверки:

```bash
npm run format:check
npm run check
npm run lint
npm test
npm run build
```

`npm run build` проверяет каталог, отсутствие legacy D3 runtime, размеры
основных и изолированных картографических чанков, 72 RU/EN-маршрута и
SEO-метаданные. Результат — 147 статических страниц.

## Структура

- `src/lib/catalog.ts` — типизированный двуязычный каталог и учебные данные;
- `src/components/charts/` — runtime-компоненты ECharts, D3, MapLibre и deck.gl;
- `src/lib/charts/` — конфигурации диаграмм, адаптеры карт и lifecycle;
- `src/pages/` — статические RU/EN-маршруты;
- `src/styles/` — дизайн-токены, адаптивные и печатные стили;
- `src/data/geo/` — локальная картографическая основа и её происхождение;
- `public/data/maps/` — локальные наборы и производные выборки для карт;
- `tests/` — контракты каталога, диаграмм и собранных маршрутов.

## Данные и происхождение

Большинство небольших учебных наборов синтетические и не предназначены для
фактических выводов. Картографические примеры используют реальные публичные
данные или компактные производные выборки; на каждой странице указан источник,
а преобразования документированы рядом с файлами данных.
Структура справочника основана на
[FT Visual Vocabulary](https://ft-interactive.github.io/visual-vocabulary/).
Программный код исходного проекта опубликован Financial Times по лицензии MIT;
лицензия не распространяется на содержание и фирменные обозначения FT.

Границы для D3-карт получены из Natural Earth и US Atlas. MapLibre использует
растровую основу OpenStreetMap/CARTO, а примеры deck.gl — данные DATA.GOV.UK,
Бюро переписи США и NYC Taxi & Limousine Commission. Подробности и атрибуция
находятся в `src/data/geo/README.md`, `public/data/maps/` и на страницах
соответствующих примеров.
