# deck.gl map data

- `uk-road-accidents.csv` is a deterministic one-in-five sample of the road
  accident coordinates used by the official deck.gl HexagonLayer example.
  Original source: DATA.GOV.UK; example data:
  <https://github.com/visgl/deck.gl-data/tree/master/examples/3d-heatmap>.
- `la-county-flows.json` contains the 80 largest absolute migration flows linked
  to Los Angeles County, derived from the official deck.gl ArcLayer example.
  Original source: US Census Bureau, 2009–2013; example data:
  <https://github.com/visgl/deck.gl-data/tree/master/examples/arc>.
- `nyc-taxi-trips.json` is the trip file used by the official deck.gl TripsLayer
  example. Original source: NYC Taxi & Limousine Commission, 16 June 2016,
  21:00–21:30; example data:
  <https://github.com/visgl/deck.gl-data/tree/master/examples/trips>.

The deck.gl example code and example-data repository are published under the
MIT license. Upstream attribution and source descriptions are preserved on the
corresponding RU and EN chart pages.
