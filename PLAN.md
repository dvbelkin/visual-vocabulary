# План завершения Visual Vocabulary

## 1. Цель первого релиза

Visual Vocabulary — двуязычный статический учебный сайт на Astro и TypeScript.
Он помогает выбрать форму визуализации, понять её ограничения и изучить
небольшой интерактивный пример.

Проект завершается как справочник из 72 типов визуализаций. Импорт
пользовательских данных, backend, учётные записи и расширение каталога не входят
в согласованный финальный объём.

## 2. Фактическое состояние

На 26 июля 2026 года:

- [x] все 72 типа имеют стабильные RU- и EN-маршруты;
- [x] все 72 production-примера перенесены в Astro без legacy iframe;
- [x] D3 используется только как согласованный алгоритмический модуль:
      `d3-delaunay`, `d3-contour` и `d3-force`;
- [x] каталог, поиск, категории и переключение языка работают без клиентского
      фреймворка;
- [x] контент хранится в типизированном двуязычном каталоге и проверяется при
      сборке;
- [x] каждая страница содержит назначение, ограничение, единицы измерения,
      пометку синтетических данных и таблицу значений;
- [x] ECharts загружается только на страницах диаграмм, специализированные и
      картографические формы вынесены в отдельные динамические чанки;
- [x] настроены typecheck, lint, unit-тесты, проверка маршрутов, production build
      и GitHub Pages;
- [x] опубликованный сайт доступен по адресу
      `https://dvbelkin.github.io/visual-vocabulary/`.

Картографическое семейство повторно открыто для содержательной переработки:
вместо одного условного набора по Европе используются подходящие реальные
геоданные и специализированные runtime-библиотеки D3, MapLibre GL JS и deck.gl.
Карты остаются в существующих восьми маршрутах и не расширяют каталог.
